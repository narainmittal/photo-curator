# Photo Curator contributor instructions

This source repository is public. Keep personal photos, names, account details, actual review choices, source paths, backups and private manifests outside it. Use only synthetic fixtures in tests and examples. Do not initialize Git at the personal project's parent directory.

Preserve originals. Never infer identities, auto-promote a memory on an uncalibrated blur score, or claim independent visual review without evidence. Keep quality separate from memory coverage. D has no gallery preview; B/D cannot finalize. A/C requires explicit choices bound to output bytes. Rendering changes invalidate review approvals.

Validate changes with the Python workflow tests and Node reviewer contract checks. A passing contract check does not establish visual browser QA. Document limitations honestly. Do not add cloud credentials or automatic deletion/upload behavior.
